# En savoir plus

Ce document est une traduction **non officielle** du livret de règles version 1.7 de Marvel Champions : Le Jeu de Cartes, édité par Fantasy Flight Games (FFG).

L'objectif de ce projet est de mettre à disposition des joueurs francophones une version actualisée aux dernières clarifications de règles publiées par l'éditeur. La traduction a été réalisée avec l'aide de l'**IA** ~~STARK~~ donc les erreurs sont inévitables.

## Contribuer au projet

Si vous êtes un expert des règles ou un passionné de mise en page, votre aide est la bienvenue !

- Traduction & Relecture : Vous avez repéré une coquille ou une tournure de phrase peu claire ?
- Suggestions : Toute idée pour améliorer cet outil de référence est appréciée.
