# Vaincre, déjouer


Si un personnage a zéro point de vie restant ou moins, ou si une manigance secondaire n'a plus de menace sur elle, elle est vaincue (ou déjouée).

  - Si un allié, un sbire ou une manigance secondaire est vaincu, il est défaussé.

  - Si une identité ou un stade du méchant est vaincu, il est retiré de la partie.
