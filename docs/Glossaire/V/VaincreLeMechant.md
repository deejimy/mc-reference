# Vaincre le Méchant

Si les points de vie du compteur du méchant sont réduits à zéro, les joueurs ont vaincu ce stade du méchant.  
Retirez de la partie le stade actuel du deck Méchant.  
Le stade suivant du deck Méchant dans l'ordre séquentiel est révélé. Réglez le compteur de points de vie du méchant comme indiqué sur ce stade.  
Si le dernier stade du deck Méchant est vaincu, les joueurs gagnent la partie.  

- La révélation d'un méchant ne peut pas être annulée.  
- Les dégâts en excès qui vainquent le stade d'un méchant ne sont pas reportés sur le nouveau stade.  
- Si le nouveau stade du méchant a le même titre que le stade précédent :  
    - Le nouveau stade du méchant est considéré comme le même personnage que le stade vaincu pour les capacités de carte (par exemple le mot‑clé `Riposte X`).  
    - Les attachements, améliorations, cartes d'état, jetons et pions autres que les pions Dégât sont reportés sur le nouveau stade.  
    - Si le méchant a été vaincu pendant son activation, il reprend cette activation en utilisant le nouveau stade du méchant.  

- Si le nouveau stade du méchant a un titre différent du stade précédent :  
    - Le nouveau stade du méchant n'est pas considéré comme le même personnage que le stade vaincu pour les capacités de carte.  
    - Les attachements, améliorations, cartes d'état, jetons et pions autres que les pions Dégât ne sont pas reportés sur le nouveau stade.  
    - Si le méchant a été vaincu pendant son activation, l'activation se termine sans se résoudre.

<summary>EN v1.8</summary>VILLAIN DEFEAT
If the villain’s hit point dial is reduced to zero, the players have defeated that stage of the villain.
Remove the current stage of the villain deck from the game.
The next sequential stage of the villain deck is revealed. Set the villain’s hit point dial as indicated by that stage.
If the final stage of the villain deck is defeated, the players win the game.
• The revealing of a villain cannot be canceled.
• Excess damage that is dealt to defeat a villain stage does not carry over to the new stage.
• If the new stage of the villain has the same title as the previous stage:
» The new stage of the villain is considered the same character as the defeated stage for purposes of card abilities (such as the retaliate X keyword).
» Attachments, upgrades, status cards, counters, and non-damage tokens on a villain carry over to the new stage.
» If the villain was defeated while activating, the villain resumes that activation using the new villain stage.
• If the new stage of the villain has a different title from the previous stage:
» The new stage of the villain not is considered the same character as the defeated stage for purposes of card abilities.
» Attachments, upgrades, status cards, counters, and non-damage tokens do not carry over to the new stage.
» If the villain was defeated while activating, the activation ends without resolving.
See also: All-Purpose Counter, Attachment, Damage, Defeat, Excess Damage, Hit Points, Status Cards, Villain
