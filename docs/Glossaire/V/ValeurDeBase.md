# Valeur de Base

C'est une valeur définie avant l'application des modificateurs.
Dans la plupart des cas, il s'agit de la valeur imprimée.

_Voir aussi : [[Modificateurs]], [[Imprime|Imprimé]]_

<details class="source">
<summary>EN v1.8</summary>BASE VALUE
A defined value before modifiers are applied. In most cases, it is also the printed value.
See also: Modifiers, Printed
</details>
