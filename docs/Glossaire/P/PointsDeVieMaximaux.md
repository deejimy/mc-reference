# Points de vie maximaux

Les points de vie maximums d'un personnage correspondent à ses points de vie de base plus ou moins tous les modificateurs de points de vie actifs sur ce personnage.

**Voir aussi** : Allié, Gagner / Perdre (une statistique), Identité,
Méchant, Modificateurs, Points de Vie, Sbire, Valeur de Base


```
MAXIMUM HIT POINTS
A character’s maximum hit points is their base hit points
plus or minus all "gets" hit point modifiers that are active on
that character.


See also: Ally, Base Value, Hit Points, Identity, Minion,
Modifiers, Villain
```
