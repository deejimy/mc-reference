# Personnage

Le terme personnage désigne les identités (héros et alter‑ego), les alliés, les méchants et les sbires.  

_Voir aussi : [[Allie|Allié]], [[Identite|Identité]], [[MechantDeckMechant|Méchant]], [[Sbire|Sbire]]_
