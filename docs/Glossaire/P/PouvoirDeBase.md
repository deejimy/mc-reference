# Pouvoir de Base


Un pouvoir de base est une statistique qui permet à un personnage d'effectuer une certaine fonction de jeu.

  - Il existe cinq pouvoirs de base différentes :

    - Le pouvoir d'attaque (ATK) pour effectuer une attaque de base.

    - Le pouvoir de contre (CTR) pour effectuer un contre de base et retirer de la menace.

    - Le pouvoir de défense (DEF) pour effectuer une défense de base et prévenir des dégâts.

    - Le pouvoir de récupération (REC) pour effectuer une récupération de base et se soigner.

    - Le pouvoir de manigance (MNG) pour effectuer une manigance de base et placer de la menace.
