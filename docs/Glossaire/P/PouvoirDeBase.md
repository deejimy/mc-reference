# Pouvoir de Base


Une puissance de base est une statistique qui permet à un personnage d'effectuer une certaine fonction de jeu.

  - Il existe cinq puissances de base différentes :

  - La puissance d'attaque (ATK) pour effectuer une attaque de base.

  - La puissance de contre (CTR) pour effectuer un contre de base et retirer de la menace.

  - La puissance de défense (DEF) pour effectuer une défense de base et prévenir des dégâts.

  - La puissance de récupération (REC) pour effectuer une récupération de base et se soigner.

  - La puissance de manigance (MAN) pour effectuer une manigance de base et placer de la menace.
