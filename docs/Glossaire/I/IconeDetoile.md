# Icône d'Étoile


L'icône étoile (![[icone_etoile.jpg|15]]) associée à une statistique ou un boost indique qu'une capacité obligatoire dans la boîte de texte correspond à ce champ. Elle sert de rappel pour vérifier le texte.

  - Si utilisée comme valeur de puissance, l'étoile vaut 0.

**Voir aussi** : Activation, Allié, Attachement, Pouvoir de base, Boost, Identité, Sbire, Méchant
