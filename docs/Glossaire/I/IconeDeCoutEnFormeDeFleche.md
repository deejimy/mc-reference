# Icône de coût en forme de flèche

Une icône de coût en forme de flèche (→) dans le texte d'une capacité permet de distinguer un coût d'un effet, suivant le format « payer le coût → résoudre l'effet ». Le texte non mis en gras avant l'icône de coût doit être payé et/ou résolu complètement avant que le texte suivant la flèche puisse être résolu.  

- <span class="new">Les réponses au texte précédant l'icône de coût se résolvent avant que le texte suivant l'icône ne soit résolu.</span>  

_Voir aussi : [[Cout|Coût]], [[Icone|Icône]]_

<summary>EN v1.7</summary>ARROW ICON
A cost arrow icon (→) in ability text distinguishes a cost from an effect, in a "pay cost → resolve effect" format. Nonbolded text before the cost arrow icon must be paid and/or resolved in full before the text after the cost arrow icon can be resolved.
• Responses to the text preceding the cost arrow icon resolve before the text following the icon resolves.
