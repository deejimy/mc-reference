# Imprimé


The word "printed" refers to the text, characteristic, or value
that is physically printed on the card.

  - If a player must pay a cost using "printed resources,"
they may use resources generated by a card’s ability,
so long as the icon(s) for the resource(s) that card
generates is printed in its text box.

  - Wild resources () cannot be spent as other
resource types for such a cost.
