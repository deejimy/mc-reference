# Attaques Contre les Alliés


Certains effets amènent un méchant ou un sbire à attaquer directement un allié. Lorsque cela se produit, tous les dégâts non défendus de cette attaque sont placés sur l'allié qui a été attaqué.

  - Le joueur qui contrôle l'allié est considéré comme le joueur attaqué.

  - Si l'attaque possède le déferlement et vainc un allié, les dégâts excédentaires sont infligés à l'identité du joueur contrôlant l'allié.
