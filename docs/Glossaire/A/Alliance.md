# Alliance


Lorsqu'un joueur déclare son intention de jouer une carte avec le mot-clé `alliance`, tout joueur peut aider à payer les coûts de cette carte.

  - Seul le joueur jouant la carte avec le mot-clé `alliance` est considéré comme résolvant cette carte.


```
ALLIANCE
When a player declares their intention to play a card with
the alliance keyword, any player(s) may help pay the costs
for that card.

  - Only the player playing the card with the alliance
keyword is considered to be resolving that card.


See also: Cost, Initiating Abilities, Keywords
```
