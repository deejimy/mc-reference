# Attaque (Action de Joueur)


Il existe plusieurs manières dont une attaque peut se produire :

  - Un héros ou un allié peut utiliser sa puissance d'attaque de base pour attaquer un ennemi. Un personnage doit s'incliner pour utiliser cette puissance. Cela inflige des dégâts égaux à la valeur d'ATK du personnage à l'ennemi.

  - Si une capacité déclenchée est étiquetée comme une attaque — comme "Action de Héros (attaque)" — la résolution de cette capacité est considérée comme une attaque de la cible spécifiée. À moins d'être spécifié par le texte de la capacité, un héros ne s'incline pas.

  - Une capacité étiquetée comme une attaque est considérée comme une attaque unique, même si elle inflige plusieurs instances de dégâts.
