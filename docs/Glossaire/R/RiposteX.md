# Riposte X


After a character with the retaliate X keyword is attacked,
deal X damage to the attacker. (X is the value next to the
retaliate keyword.)

  - The character with retaliate X must be in play after
the attack resolves to deal this damage.

  - The order of resolution for abilities surrounding the
retaliate keyword is as follows:
1. Abilities that trigger "after [character] takes any
amount of damage..."
2. Retaliate X
3. Abilities that trigger "after [character] is
attacked..." or "after [character] attacks [and
damages/defeats]..."


See also: Ally, Attack (Enemy Activation), Attack (Player
Ability Type), Damage, Identity, Keywords, Minion,
Reminder Text, Villain
