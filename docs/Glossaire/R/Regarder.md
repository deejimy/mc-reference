# Regarder, regardé

Si une capacité demande à un joueur de regarder des cartes qui sont normalement cachées à la vue des joueurs, seul le joueur qui résout la capacité peut consulter ces cartes. 
Cependant, ce joueur est autorisé à partager n’importe quelles informations aux autres joueurs concernant ces cartes.

- Pendant qu'un joueur regarde des cartes dans un deck, ces cartes sont toujours considérées comme faisant partie de ce deck.
    - Après avoir regardé des cartes dans un deck, ces cartes sont remises dans ce deck dans le même ordre.
