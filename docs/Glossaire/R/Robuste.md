# Robuste


Un personnage avec le mot-clé `robuste` ne peut être ni sonné ni désorienté. Si un personnage devient robuste alors qu'il a ces cartes d'état, elles sont retirées.

**Voir aussi** : Allié, Désorienté, Identité, Mots-clés, Sbire, Cartes d'état, Sonné, Méchant

STALWART
A character that has the stalwart keyword cannot be
stunned or confused.

  - If a character gains the stalwart keyword while they
have a stunned and/or confused status card, each
stunned and/or confused status card is removed from
that character.
