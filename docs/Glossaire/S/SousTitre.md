# Sous-Titre

Certaines cartes Allié ont un sous-titre sous leur titre. Un sous-titre correspond à un nom alternatif qu’un personnage utilise parfois.

_Voir aussi : [[IconeUnique|Icône unique]]_


**EN v1.7**:  
```
SUBTITLE
Some ally cards have a subtitle beneath the title. A subtitle represents an alternate alias a character sometimes uses.
```
