# Tiret (Valeur)


Une valeur représentée par un tiret (–) indique que cette valeur ne peut pas être utilisée.

  - Si une carte possède un tiret (–) comme valeur de coût, cette carte ne peut pas être jouée et ne peut entrer en jeu que par d'autres moyens.

  - Si la puissance d'un personnage (ATK, DEF, REC, MNGet CTR) possède un tiret (–) comme valeur, le personnage ne peut pas s'incliner pour utiliser cette puissance.

  - Si une étape de jeu ou une capacité de carte fait référence à une valeur représentée par un tiret (–), cette valeur est traitée comme un 0 non modifiable. (Par exemple, si une capacité cible "l'allié ayant la MNGla plus basse", un allié avec un tiret pour sa MNGest considéré comme ayant la même MNGqu'un allié avec une MNGde 0.)
