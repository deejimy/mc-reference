# Texte de Rappel


Certaines capacités peuvent inclure un texte de rappel. Le texte de rappel est en italique et entre parenthèses (comme ceci). Il n'a aucun effet sur le jeu et sert uniquement à rappeler une règle ou une fonction spécifique.


```
REMINDER TEXT
Some card abilities may include reminder text. Reminder
text is italicized and in parentheses (like this). Reminder text
has no effect on the game and is only intended to remind a
player of a specific game function or rule.
```
