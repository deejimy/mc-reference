# Ténacité  

Quand un personnage doté du mot‑clé `Ténacité` entre en jeu, placez une carte d'état Tenace dessus.  
- <span class="new">Le mot-clé Ténacité est équivalent à la capacité déclenchée suivante : "Réponse Forcée : Après que ce personnage entre en jeu, donnez-lui une carte d'état Tenace."</span>
