# Temporaire

Une carte avec le mot-clé `temporaire` doit être défaussée du jeu à la fin du round.

_Voir aussi : [[MotsCles|Mots-clés]]_


<details class="source">
<summary>EN v1.8</summary>TEMPORARY
A card with temporary must be discarded from play at the end of the round.
• The temporary keyword is equivalent to the following triggered ability: "Forced Interrupt: When the round ends, discard this card from play."
See also: Keywords
</details>
