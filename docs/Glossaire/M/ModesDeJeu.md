# Modes de Jeu


Marvel Champions peut être joué selon différents modes de difficulté :

  - Mode Standard : utilise le set Standard de cartes de rencontre.

  - Mode Expert : utilise le set Standard et le set Expert.

  - Mode Héroïque : augmente le nombre de cartes de rencontre distribuées à chaque joueur pendant la phase du méchant.

**Voir aussi** : Set Expert, Set Standard
