# Manigance (type de carte)


Le mot "manigance" désigne trois types de cartes : manigances principales, manigances annexes de joueur et manigances annexes.

  - Si une capacité place ou retire de la menace d'une "manigance", le joueur choisit laquelle.

**Voir aussi** : Manigance principale, Manigance annexe de joueur, Manigance annexe


**EN v1.7**:  
```
SCHEME (CARD TYPE)
The word "scheme" denotes three different card types: main schemes, player side schemes, and side schemes.
• If a card ability places threat on or removes threat from "a scheme," the player resolving that ability chooses which scheme—main scheme or side schemes—that ability affects.
See also: Main Scheme, Player Side Scheme, Side Scheme
```
