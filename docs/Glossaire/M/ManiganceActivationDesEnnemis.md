# Manigance (activation des ennemis)


Manigancer est un type d'activation d'ennemi. Étapes :
1. Si c'est un méchant ou un sbire avec vilenie, donnez-lui une carte de boost face cachée.
2. Résolvez les cartes de boost (retourner, appliquer les capacités étoile, augmenter la valeur de MAN par les icônes de boost).
3. Placez de la menace sur la manigance principale égale à la valeur de MAN modifiée.
