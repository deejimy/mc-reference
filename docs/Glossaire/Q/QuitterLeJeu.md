# Quitter le jeu


L'expression "quitte le jeu" se réfère à tout moment où une carte passe du jeu à une zone hors-jeu.

  - Lorsqu'une carte quitte le jeu, tous les pions qui se trouvaient sur elle sont replacés dans la réserve générale, et toutes les cartes d'état qui se trouvaient sur elle sont remises dans leurs piles respectives.

  - Toutes les cartes attachées à une carte qui quitte le jeu sont défaussées.

  - Si une carte quitte le jeu, toutes les capacités de carte qui étaient actives sur cette carte (à l'exception des capacités Réponse ou d'interruption déclenchées par le départ de la carte) cessent d'être actives.

**Voir aussi** : En jeu et Hors-jeu, Vaincre


**EN v1.7**:  
```
LEAVES PLAY
The phrase "leaves play" refers to any time when a card transitions from an in-play area to an out-of-play area.
Defeating a character, discarding a card from play, placing a card in the victory display, or removing a card from the game are all different means by which a card can leave play.
• When a card leaves play, there is no memory of its previous state and it is considered to be a new copy of the card.
• When a card leaves play:
» » Discard each card attached to or tucked under that card.
» » Discard each boost card given to that card.
» » Return each token and status card on that card to the supply.
See also: Defeat, Discard, Discard Pile, Enters Play, In Play and Out of Play, Removed from the Game, Victory Display
```


**FR v1.4**:  
```
QUITTER LE JEU
Les mots « quitte le jeu » font référence à chaque situation pendant laquelle une carte effectue une transition depuis une zone en jeu vers une zone hors jeu. Vaincre un personnage, défausser une carte qui est en jeu, placez une carte dans la pile de victoire, ou retirer une carte de la partie sont différentes façons pour une carte de quitter le jeu.
• Quand une carte quitte le jeu, elle ne conserve pas le statut qu’elle avait juste avant de quitter le jeu, on considère qu’il s’agit d’un nouvel exemplaire de cette carte.
```
