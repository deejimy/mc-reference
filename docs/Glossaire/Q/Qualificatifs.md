# Qualificatifs


Si le texte d'une capacité inclut un qualificatif suivi de plusieurs termes, le qualificatif s'applique à chaque élément de la liste, si applicable. Par exemple, dans la phrase "chaque personnage et attachement prêt", le mot "prêt" s'applique à la fois à "personnage" et à "attachement".


```
QUALIFIERS
If ability text includes a qualifier followed by multiple terms,
the qualifier applies to each item in the list, if applicable.
For example, in the phrase "each ready character and
attachment" the word "ready" applies to both "character"
and "attachment."
```
