# Utilisations (X "Type")


Lorsqu'une carte avec ce mot-clé entre en jeu, placez X pions polyvalents dessus. Le mot suivant la valeur identifie le type d'utilisations.

Chaque carte avec ce mot-clé possède une capacité qui utilise ces pions comme coût.

Quand le dernier pion est retiré, défaussez la carte.

**Voir aussi** : jeton polyvalent, Défausse, Entre en jeu, Mots-clés, Quitte le jeu, Texte de rappel


```
USES (X "TYPE")
When a card with this keyword enters play, place X allpurpose
counters from the token pool on the card. The
word following the value establishes and identifies the type
of uses the card holds.
Each card with this keyword also has an ability that
references the type of use established by the keyword as
part of the cost.
When the last all-purpose counter is removed from a card
with uses, discard that card.


See also: All-Purpose Counter, Discard, Enters Play,
Keywords, Leaves Play, Reminder Text
```
