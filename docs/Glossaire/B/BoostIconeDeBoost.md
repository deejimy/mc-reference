# Boost, icône de boost


Chaque fois que le méchant attaque ou manigance, il reçoit une carte face cachée en tant que carte de boost. Les sbires possédant le mot-clé vilenie reçoivent également une carte de boost lorsqu'ils s'activent. Pendant l'activation, chaque carte de boost est retournée face visible. Ajoutez le nombre d'icônes de boost à la valeur d'ATK ou de MAN de l'ennemi.
