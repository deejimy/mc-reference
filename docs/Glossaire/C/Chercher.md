# Chercher


Lorsqu'un joueur cherche une carte, il peut regarder toutes les cartes de la zone spécifiée. S'il trouve une carte correspondant aux critères, il l'ajoute à la zone indiquée.

  - Si plusieurs cartes correspondent, le joueur choisit.

  - Après une recherche dans un deck, celui-ci doit être mélangé.

**Voir aussi** : Paquet de rencontre, Trouver, Deck de joueur, Mélanger


```
SEARCH
When a player is instructed to search for a card, the player is
permitted to look at each of the cards in the searched area.
If the player finds a card that satisfies the criteria of the
search, the player adds that card to the game area indicated
by the instructions on the search effect.

  - If a player finds multiple cards that satisfy the criteria
of a search, the player chooses among those options.

  - Cards being searched are not considered to leave the
searched area.

  - If any portion of a deck is searched, upon completion
of that game step, game function, or card ability,
shuffle that entire deck.

  - If a player is instructed to "search [their] collection"
for a card, the player looks through all of their Marvel
Champions cards outside of the current game for the
specified card.

  - They become the owner of that card until the end
of the game.


See also: Encounter Deck, Find, Player Deck, Shuffle
```
