# Cartes d'état


Les cartes d'état représentent différents états (Sonné, Désorienté, Tenace).

  - Un personnage ne peut avoir qu'une seule carte de chaque type (sauf s'il est Solide).

  - Les capacités des cartes d'état ont la priorité sur les capacités déclenchées conflictuelles.

  - Désorienté : annule la prochaine manigance ou le prochain contre.

  - Sonné : annule la prochaine attaque.

  - Tenace : prévient la prochaine instance de dégâts.
