# Chaque Joueur


Lorsque chaque joueur reçoit l'instruction de résoudre un effet, chaque joueur résout cet effet l'un après l'autre.

  - Si l'effet ne spécifie pas dans quel ordre les joueurs doivent résoudre l'effet, le premier joueur décide de l'ordre.

  - Si un joueur ne peut pas résoudre entièrement cet effet, il le résout aussi complètement que possible. Par exemple, si chaque joueur reçoit l'instruction de défausser un certain nombre de cartes du deck Rencontre et que le paquet se vide alors qu'un joueur est en train de défausser, ce joueur s'arrête de défausser dès que le paquet est vide. Une fois le paquet réinitialisé (et qu'un pion d'accélération a été placé à côté du deck de manigance principale), les joueurs restants reprennent la défausse.
