# Cartes spécifiques au scénario


Les cartes "spécifiques au scénario" appartiennent au set d'un scénario donné.

  - Un scénario doit inclure toutes les cartes spécifiques associées.

  - Elles sont généralement réparties en trois paquets : le deck du méchant, le deck de manigance principale et le deck Rencontre.
