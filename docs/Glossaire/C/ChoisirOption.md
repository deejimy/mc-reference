# Choisir (Option)


Certaines capacités ordonnent à un joueur de choisir entre plusieurs options. Par exemple, "Choisissez soit de subir 1 dégât, soit de défausser 1 carte de votre main."

  - Lorsqu'une carte de rencontre nécessite qu'un joueur choisisse une option, celui-ci ne peut pas choisir une option qui nécessite une ou plusieurs cibles s'il n'y a pas de cibles valides pour cette option.

  - Lorsqu'une carte de joueur nécessite qu'un joueur choisisse une option, celui-ci ne peut pas choisir une option qui ne peut pas être au moins partiellement résolue. Cela inclut les options qui :

  - Ont un coût que le joueur ne peut pas payer.

  - Nécessitent une ou plusieurs cibles et il n'y a pas de cibles valides.
