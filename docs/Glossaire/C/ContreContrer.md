# Contre, contrer


Some game effects and card abilities reference a thwart
attempt. There are a few different ways this can occur:

  - A hero or ally can use their basic thwart power to
thwart a scheme. A character must exhaust to use this
power. This removes threat equal to the character’s
THW value from the scheme.

  - A character can only initiate a basic thwart if
there is a scheme with at least one threat for the
character to remove or if that character is confused.

  - If a triggered ability is labeled as a thwart—such
as "Hero Action (thwart)"—resolving that ability is
considered to thwart the specified scheme. Unless
specified by the ability’s text, a hero does not exhaust
when using such an ability.

  - An ability labeled as a thwart is considered a
single thwart, even if that thwart removes multiple
instances of threat.

  - If an ability increases the amount of threat an
ability labeled as a thwart removes and that ability
removes multiple instances of threat, each of those
instances that does not use the word "additional" is
increased by the specified amount.
