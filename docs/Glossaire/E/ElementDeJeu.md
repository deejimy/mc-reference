# Elément de Jeu


A game element is a component or person involved in
playing a game of Marvel Champions. All of the following
are game elements:

  - Cards

  - Decks

  - Discard Piles

  - Hands (of cards)

  - Hit Point Dials

  - Players

  - Tokens


See also: Card Types, Deck, Discard Pile, Player, Target
