# Elément de Jeu

Un élément de jeu est un composant ou une personne impliquée dans une partie de Marvel Champions.  

- Cartes  
- Decks  
- Piles de défausse  
- Mains (de cartes)  
- Cadrans de points de vie  
- Joueurs  
- Jetons

<summary>EN v1.8</summary>GAME ELEMENT
A game element is a component or person involved in playing a game of Marvel Champions. All of the following are game elements:
• Cards
• Decks
• Discard Piles
• Hands (of cards)
• Hit Point Dials
• Players
• Tokens See also: Card Types, Deck, Discard Pile, Player, Target
