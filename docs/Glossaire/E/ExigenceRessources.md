# Exigence (Ressources)

Une carte portant le mot-clé « Exigence » ne peut être jouée que si, lors du paiement de son coût, chaque ressource du type précisé a été dépensée pour ce paiement.  

- Une carte dotée du mot-clé Exigence ne peut pas être jouée en « ignorant son coût en ressources », car les ressources requises ne peuvent pas être payées pour elle.  
<span class="new">- Le mot-clé Exigence (Ressources) est équivalent à la capacité constante suivante : "Lors du paiement du coût en ressources de cette carte, vous devez dépenser les ressources suivantes : [resources]."</span>

<details class="source">
<summary>EN v1.8</summary>REQUIREMENT (RESOURCES)
A card with the requirement keyword cannot be played unless each resource of the specified type is spent while paying for that card’s cost.
• The requirement (resources) keyword is equivalent to the following constant ability: "When paying this card’s resource cost, you must spend the following resources: [resources]."
• A card with the requirement keyword cannot be played "ignoring its resource cost" because the required resources cannot be paid for it.
See also: Cost, Initiating Abilities, Keywords, Resource
</details>
