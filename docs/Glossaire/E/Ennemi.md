# Ennemi


Un ennemi est un sbire ou un méchant.
Lorsqu'il est utilisé comme descripteur, "ennemi" se réfère aux éléments de jeu qui appartiennent au scénario : "cartes ennemies", "capacités ennemies", etc.

**Voir aussi** : Élément de jeu, Sbire, Méchant
