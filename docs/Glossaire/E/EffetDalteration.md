# Effet d'altération


Un effet d'altération modifie la résolution d'une capacité qui le précède. Les types d'effets d'altération incluent :
Supplémentaire — Le mot "supplémentaire" désigne un modificateur d'une capacité ou d'un état de jeu. Le modificateur supplémentaire est résolu simultanément avec toute capacité qu'il modifie et sous les mêmes conditions que cette capacité.
Déjà — Le mot "déjà" désigne la résolution d'une capacité alternative si une condition spécifique est remplie. L'effet "déjà" vérifie si cette condition est remplie avant que la capacité précédente ne tente de se résoudre. Si c'est le cas, l'effet "déjà" se résout à la place.
Chaque fois — L'expression "chaque fois" désigne une interruption temporaire d'une capacité en cours de résolution. Lorsqu'une condition spécifiée par l'effet "chaque fois" est remplie, la résolution de la capacité précédente s'arrête, l'effet "chaque fois" se résout dans son intégralité, puis la capacité précédente continue de se résoudre.
Cette/Cette Activation/Attaque/Contre — Les effets qui se réfèrent à "cette" activation, attaque ou contre désignent un modificateur de cette activation, attaque ou contre.

  - Si "cette activation/attaque/contre" fait partie d'une condition pour un effet, cela n'en fait pas un effet d'altération.
