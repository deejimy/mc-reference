# Ensuite


Si le texte d'une capacité inclut le mot "puis", le texte précédant le mot "puis" doit être entièrement vrai ou résolu avant que le reste de l'effet décrit après "puis" puisse être résolu.

  - Si le texte avant le "puis" est entièrement résolu, le texte après le "puis" doit également tenter de se résoudre.

  - Si le texte avant le "puis" n'est pas entièrement résolu, le texte après le "puis" ne tente pas de se résoudre.
