# Ensuite


Si le texte d'une capacité inclut le mot "puis", le texte précédant le mot "puis" doit être entièrement vrai ou résolu avant que le reste de l'effet décrit après "puis" puisse être résolu.

  - Si le texte avant le "puis" est entièrement résolu, le texte après le "puis" doit également tenter de se résoudre.

  - Si le texte avant le "puis" n'est pas entièrement résolu, le texte après le "puis" ne tente pas de se résoudre.


```
"THEN"
If the effect text of an ability includes the word "then",
the text preceding the word "then" must be fully true or
resolved before the remainder of the effect described after
the word "then" can be resolved.

  - If the pre-"then" text of an effect fully resolves,
the post-"then" text of the effect must also
attempt to resolve.

  - If the pre-"then" text of an effect does not fully
resolve, the post-"then" text does not attempt to
resolve.
```
