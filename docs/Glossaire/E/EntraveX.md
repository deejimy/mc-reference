# Entrave X


Lorsqu'une carte avec le mot-clé `entrave X` entre en jeu, placez X menaces sur cette carte. (X est la valeur à côté du mot-clé `entrave`.)

**Voir aussi** : Entre en jeu, Mots-clés, Texte de rappel, Révéler, Menace


**EN v1.7**:  
```
HINDER X
When a card with the hinder X keyword enters play, place X threat on that card. (X is the value next to the hinder keyword.) See also: Enters Play, Keywords, Reminder Text, Reveal, Threat
```
