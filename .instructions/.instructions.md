# Contexte
Créer un référentiel du jeu Marvel Champions LCG, avec des définitions et des explications pour les termes et mécaniques du jeu. Le contenu est en français et vise à aider les joueurs à mieux comprendre les règles et les interactions du jeu. Les règles existantes sont en v1.7 en Anglais uniquement, et le but est de fournir une traduction et une adaptation complètes en français.

# TECHNIQUE
Projet MkDocs utilisant le thème Material for MkDocs. Le contenu est écrit en Markdown avec une structure de dossiers organisée pour les différentes sections du guide de référence. Le fichier mkdocs.yml configure le site, y compris le nom, l'URL, le thème, les extensions Markdown et les plugins utilisés.
Hébergé sur GitHub Pages pour un accès facile et une distribution publique.

## Instructions de traduction
1. Langue et fichiers

- Tout le contenu doit être entièrement en français — ne pas laisser de sections en anglais. Toujours vérifier que la page est intégralement traduite.
- Appliquer ces instructions à tous les fichiers Markdown dans le projet (glob pattern: `**/*.md`).


2. Mise en forme

- Titres : `#` pour les articles principaux, `##` pour sections, `###` pour sous-sections.
- Pas de retours de ligne forcés à l'intérieur des paragraphes ; utilisez des sauts de ligne simples pour séparer les paragraphes.
- Listes : niveau 1 avec `•` (puce simple), niveau 2 avec `-` (tirets) pour respecter la charte visuelle du projet.
- Voir aussi : Utiliser la section **Voir aussi** à la fin des articles pour référencer d'autres articles pertinents, en utilisant la syntaxe `**Voir aussi**: _mot1, _mot2_`.

4. Terminologie

- Utilisez la table de correspondance fournie dans la section « Aide à la traduction ». Si un terme spécifique manque.
